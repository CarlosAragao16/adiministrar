# 💰 Financeiro

Um sistema completo de gerenciamento financeiro pessoal, desenvolvido para facilitar o controle de receitas, despesas, orçamento e metas financeiras.

## 🚀 Sobre o projeto

O Financeiro é uma aplicação web responsiva criada para ajudar o usuário a organizar sua vida financeira de forma simples e visual.

### ✨ Funcionalidades

- 📊 Dashboard financeiro
- 💰 Controle de receitas e despesas
- 🧾 Registro de transações
- 📅 Organização por categorias
- 🎯 Criação e acompanhamento de metas
- 📈 Relatórios financeiros
- 💵 Controle de orçamento
- 🤖 Assistente financeiro com IA
- 📱 Interface responsiva para celular, tablet e computador
